# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

Build app UI in `src/`. Keep `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs`, and `tests/sites-worker.test.mjs` intact so the same local prototype can be handed to Sites. Before a Sites handoff, run `npm run build` and `npm run test:sites`; the build must leave `dist/client/index.html`, `dist/server/index.js`, and `dist/.openai/hosting.json`.

## Prototype feedback

- 2026-08-31: Full functionality audit (every control exercised in-browser). Fixes and decisions:
  - Timeline playback and scrubbing now interpolate the camera along the active track's keyframes (`cameraAtTime` + `easeValue` in `src/editorState.js`, playhead effect in `App.jsx`). The effect is keyed on the playhead only so manual drags and keyframe-chip selections keep their pose. Video export follows the same keyframed path instead of the old sinusoidal drift, honors the selected size (1080P no longer clamps to 720P), maps Quality to `videoBitsPerSecond`, and implements Motion Blur as per-frame alpha blending (Off/Low/Med/High).
  - Media upload/paste/drop were silently discarded: the history dedupe compared `getSerializableProject()` output, which strips blob-URL media, so an upload serialized identical to the previous state. The dedupe now compares full project JSON; persistence still uses `getSerializableProject`. Superseded blob URLs stay alive until unmount so undoing back to an earlier shot still renders its media.
  - Fast double-clicks on the tour's Next could push `tourStep` past 8 and the `tourContent[step-1]` destructuring crashed React and unmounted the app. Step is clamped and `TourModal` guards out-of-range steps.
  - All 12 effects now have a visible stage implementation. Previously-dead ones (Glass Border, Depth, Sharpen, Fish Eye, Screen Fade, Ghost, Liquid Glass) render as per-effect child spans inside `.three-effects-overlay` (see `editor-enhancements.css`), avoiding pseudo-element collisions. Grain, Pixel Grid, Chromatic Abb., and Screen Fade also apply in canvas exports; Fish Eye / Depth / Ghost / Liquid Glass / Sharpen are stage-preview-only (canvas export keeps its flat re-render).
  - The mobile Blur dock is wired: `.stage-dof-layer` overlays the stage with a masked `backdrop-filter` driven by blur strength/size/falloff/mode (radial/directional/tilt) plus a subtle bokeh texture. Stage-preview only — exports do not include DOF.
  - The "Add keyframe at playhead" diamond buttons on camera sliders were dead (`preventDefault` only); they now pin a camera keyframe via `addCameraKeyframe`. Lighting sliders no longer show one (lighting isn't keyframed). Keyframe chips and lane dots show a selected state.
  - Regression: `npm run test:editor` covers `scenePatch`, `easeValue`, and `cameraAtTime`; `scripts/scene-probe.mjs` passes; `npm run build` + `npm run test:sites` pass.
