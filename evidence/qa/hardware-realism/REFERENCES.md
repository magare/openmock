# Hardware reference pass — 2026-09-12 / 2026-09-13

These nine devices use measured procedural geometry, not newly acquired manufacturer meshes. Existing manufacturer models, including the iPhone 17 comparison, retain their existing rendering path. Fine engravings and internal components are simplified; user media continues to cover the active display.
